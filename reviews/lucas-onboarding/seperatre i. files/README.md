# Einzelne HTML-Seiten

index.html öffnen. 63 eigenständige Ansichten; jede HTML-Datei enthält die vollständige Anwendung samt Styles, Bildern und Demo-Bankdaten. Kein Server erforderlich. Der genaue Dateiname des Ordners ist wie gewünscht „seperatre i. files“.

Die richtige Ansicht wird durch das Ausführen der bestehenden Demo-Aktionen geöffnet, ohne eigene Seiten-Templates oder Änderungen an den App-Funktionen. Spätere Ansichten benötigen kurz für die ursprüngliche PIN-/Scan-Animation. Danach ist die Seite regulär bedienbar.

Enthalten: Onboarding, alle drei Fragen für jeden der elf Lebenspläne, bestehende Themenprioritäten, Datenquellen und Eingabemodi, Hauptansichten, vier Lektionen und Mobile Banking. Nicht jede mögliche Zwischenmeldung, Dialog- oder Antwortkombination ist eine eigene Datei.

Der zuletzt besprochene Vorschlag zum Ersetzen der Daumen wurde nicht umgesetzt. Jede Datei zeigt den aktuellen freigegebenen Designstand. Demo-Antworten sind bei direkten Fragenansichten exemplarisch vorausgewählt.

Neu erzeugen: im übergeordneten Ordner node export-pages.mjs ausführen, nachdem die einzelne Gesamt-HTML exportiert wurde.

## Prüfung

Alle 63 Dateien im Browser direkt geöffnet. Jede meldet den vorgesehenen Exportzustand ohne Fehler; Ergebnisse stehen in browser-pruefung.json. Prüfung über lokalen HTTP-Server; file:// wurde nicht separat automatisiert getestet.
