## English widget website

Open [the English widget website](PULS_App_English.html) in a browser. This adapts the English V10 prototype into a responsive standalone HTML surface without a smartphone frame, studio controls, or a banking home page. The scope is the financial wellbeing widget and its detail, learning, goal, and demo coach views. Banking data and actions remain illustrative.

## Interactive onboarding prototype

Open [PULS Onboarding V1 — English](PULS_Onboarding_V1_English.html) in a browser. The standalone HTML file works without installation or a server.

The in-branch concept includes simulated card/NFC sign-in, seven interactive questions, selectable life moments, a goal timeline, an adjustable spending chart with independent sliders, exact percentage inputs, and an explicit balance action, three concise questions about future support, answer review, and a confirmation gate before the demo widget is unlocked.

This is a prototype: no banking API, card hardware, or live app activation is connected. Answers are stored in the browser tab for the session and cleared on session end or five minutes of inactivity. The onboarding uses a centred layout with a progress bar and adapts to mobile screens.
